# Code of conduct

Be decent. Assume the other person is trying to help.

Concretely: no harassment, no personal attacks, no dismissiveness about
someone's experience level. Criticise code and ideas as much as you like —
that is the job — but not people.

Reported problems go to alec@mcleod.co and are handled
privately. Maintainers may remove comments, close pull requests, or block
accounts.

Adapted in spirit from the Contributor Covenant, kept short because a document
nobody reads protects nobody.
